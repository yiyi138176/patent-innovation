# 基于大语言模型专利文本特征的企业经济结果研究

20261009 智能大数据 fxy 笔试　｜　冯馨逸　武汉理工大学经济学院

## 一、这个项目在做什么

**研究问题**：专利文本中蕴含着丰富但难以结构化的技术信息。这些信息是否包含多个相互独立的维度？如果是，哪个维度最能反映企业的经营结果？

**研究设计**：题目将研究拆为四个部分，四者构成「找线索 → 下判断」的递进关系。

| 部分 | 要回答的问题 | 主要产出 |
|---|---|---|
| **（i）** | 数量类专利特征对经济结果有没有差异化解释与预测能力？关系是线性还是非线性？ | 18 个 R² 的比较 |
| **（ii）** | 大语言模型提取的语义特征有没有增量解释力？含不含正交信息？ | 增量 R²、正交信息占比 |
| **（iii）** | 四个语义维度里哪个最重要？ | 逐维度增量排名 |
| **（iiii）** | 跨领域整合度与企业经济结果之间是什么关系？ | 四类固定效应回归 + 双重机器学习 |

## 二、数据

| 数据 | 来源 | 规模 |
|---|---|---|
| 专利数据 | 题目提供的 152 个 Excel 文件 | 117,711 条专利 |
| 公司财务数据 | akshare 财经数据接口 | 144 家 × 86 个变量，2015–2025 |

| 企业成立日期 | 同上 | 143 家公司 |

**最终样本**：143 家公司 / 1,259 个观测 / 2015–2025 年

**语义特征提取**：使用智谱 GLM-4-Flash 对 12,166 条专利的标题与摘要逐条评分，
提取技术新颖性、科学基础强度、跨领域整合度、商业化距离四个维度。
提示词经过四轮迭代（见 `prompts/`），共消耗 1,777 万 token。

## 三、主要结果

### （i）数量类特征

跨公司维度上几乎不具备解释力（R² 接近 0 或为负）；公司内维度上可解释约 18% 的
总资产净利润率年度波动；在 9 组比较中线性模型胜出 8 组，说明关系主要是线性的。

### （ii）语义特征

四个语义特征中 **45%–65% 的变异无法被数量特征解释**（正交信息占比），
平均相关系数仅 0.21；但增量解释力有限（约 **+0.01**）。

**稳健性发现**：四个语义维度彼此高度相关（0.66–0.92）。通过「将四个维度拆成四次
独立调用」的对照实验（相关系数 0.725 对 0.679，未下降）证明，这一高相关是专利的
客观属性，而非提示词设计造成的锚定效应。本研究的样本中四个维度并非相互独立，
这一点与题目前提存在张力，已在报告中如实说明。

### （iii）维度重要性

跨领域整合度在三个结果变量上的增量排名均为第一。

### （iiii）计量识别

在控制**企业、年份、行业×年份、地区×年份**四类固定效应及 12 个数量类专利特征，
并使用**企业层面聚类稳健标准误**的条件下：

| 被解释变量 | 主回归系数 | p 值 | DML-随机森林 | DML-LASSO |
|---|---|---|---|---|
| SA 指数（融资约束，主） | +0.0011 | 0.831 | +0.0029 | +0.0015 |
| 资产负债率（杠杆） | -0.229 | 0.773 | -0.013 | -0.273 |
| 总资产净利润率（盈利） | +0.014 | 0.974 | +0.231 | +0.031 |
| **主营业务收入增长率（成长）** | **-4.142** | **0.034** | -3.109 | **-4.282** |

**跨领域整合度与企业主营业务收入增长率显著负相关**（-4.14，p<0.05），
且在双重机器学习的两种学习器下高度一致；对融资约束与盈利能力无显著影响。

**识别策略**：双重机器学习（DML，Chernozhukov et al. 2018）。先用机器学习分别拟合
E[y|Z] 与 E[x|Z]，再对两个残差回归。使用 5 折交叉拟合，并以随机森林与 LASSO
两种学习器互相验证。为与基准回归保持固定效应设定一致，先用交替投影法
（alternating projections）将全部变量对四类固定效应偏回归，再对残差执行 DML。

## 五、如何复现

### 5.1 环境

```
Windows 11 + Python 3.14.8
pandas / numpy / scikit-learn / pyfixest / requests / akshare / statsmodels
版本见 requirements.txt
```

### 5.2 运行顺序

```bash
# 数据准备
python extract_codes.py            # 从 152 个 Excel 提取股票代码
python check_codes.py              # 用 A 股官方代码表校验（发现 3 处问题）
python fetch_financials.py         # 抓取企业财务数据
python check_coverage.py           # 检查变量年份覆盖率
python build_patent_table.py       # 专利明细聚合为公司—年份特征
python build_dataset.py            # 合并生成主数据集

# （i）基准特征建模
python model_i.py

# （ii）（iii）语义特征
python score_patents.py            # 调用大模型批量打分（需 config.py 中的 API Key）
python review_scores.py            # 检查打分质量
python model_ii.py                 # 增量解释力 + 正交性 + 逐维度重要性

# （iiii）计量回归
python fetch_industry_region.py    # 补抓行业与地区
python fetch_found_date.py         # 补抓成立日期
python build_sa_index.py           # 构造 SA 融资约束指数
python model_iiii.py               # 主回归 + 稳健性检验
python model_iiii_dml_fixed.py     # 双重机器学习
```

**注**：`config.py` 存放 API 密钥，已加入 `.gitignore`，需自行创建：

```python
ZHIPU_API_KEY = "你的密钥"
```

### 5.3 Stata 复现

```stata
* 安装依赖
ssc install ftools, replace
ssc install reghdfe, replace
ssc install estout, replace

* 运行
cd "你的路径/stata"
do iiii_regression.do
```

`iiii_regression.do` 包含描述性统计、主回归、逐维度回归、滞后检验、
聚类层级稳健性检验与结果导出，可复现报告 4.4 节的全部结果。

## 六、说明

### 6.1 关于计量工具

题目要求使用 Stata 完成（iiii）的计量分析。考虑到 Stata 正版授权的实际约束
（官方学生版 48 美元/半年且仅支持国际信用卡支付，中国区官方代理约 1000 元），
本文主体分析使用 Python 的 `pyfixest` 完成。该方法与 Stata 的 `reghdfe`
在**高维固定效应吸收**与**聚类稳健标准误**上实现等价，得到相同的系数与标准误。

为满足可复现性要求，本项目同时提供了 `stata/main_dataset.dta`（Stata 原生格式
数据集，变量名全英文）与 `stata/iiii_regression.do`（完整 do 文件）。
持有 Stata 授权者运行该 do 文件即可完整复现全部计量结果。

### 6.2 关于代码开发

本项目的分析框架、数据决策、变量选择、模型设定与结果解读由作者完成。
代码在开发过程中使用大模型辅助编写与调试，全部决策过程记录于 `决策记录.md`
（D1–D21），每一步的方法选择均有可追溯的理由。

### 6.3 数据说明

原始专利数据（152 个 Excel，约 340MB）与 176MB 的专利明细文件未纳入版本控制，
详见 `.gitignore`。分子样本抽查文件 `data/llm/抽查_原文与打分_v*.csv` 可由
`review_scores.py` 重新生成。
