# prompts/ 目录说明

本目录存放全部提示词文件。为避免混淆，各文件用途如下。

## 一、四版完整提示词（批量打分用）

这四份是实际发送给智谱 GLM-4-Flash 的提示词，每条专利一次调用、一次返回四个维度的分数。

| 文件 | 分制 | 主要改动 | 打分效果 |
|---|---|---|---|
| `prompt_v1.txt` | 1–5 分 | 抽象锚点，无示例 | 85% 打 3 分，缺乏区分度 |
| `prompt_v2.txt` | 1–5 分 | 增加 few-shot 示例 | 仍约 75% 打 3 分，未见改善 |
| `prompt_v3.txt` | 1–10 分 | 改分制 + 加入专利类型线索 + 反聚集指令 | 取值种类由 3 种升至 8 种 |
| `prompt_v4.txt` | 1–10 分 | 修正「商业化距离」定义（明确与技术含量无关，外观设计给 1–2 分） | **最终采用版本** |

**v4 为本项目全量打分（12,166 条专利）使用的版本。**

## 二、设计文档

`设计文档_维度定义与评分锚点.txt`

v1 阶段的维度定义与评分锚点原始设计稿，记录了四个维度各自的定义、10 个分档的判定标准
以及设计时的取舍考虑。它不是直接发送的提示词，而是提示词的设计依据。

## 三、维度独立性检验用提示词

`prompt_split_维度独立性检验.txt`

用于「维度独立性对照实验」：将四个维度拆成**四次独立调用**（每条专利调用 4 次），
与 v4 的一次调用四维度相比，检验维度间高相关是否由同一次调用造成。

实验结论：分开调用并未降低维度间相关性（平均相关系数 0.725 对 0.679），
说明高相关是专利的客观属性，而非提示词的锚定效应。详见报告 4.2 节「稳健性检验」。

执行脚本：`compare_split.py`、`test_independence.py`
